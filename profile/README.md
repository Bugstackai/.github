# Bugstack

**Autonomous software maintenance.** Bugstack finds what breaks, proves the fix, and opens the pull request.

- **What it handles:** crashes, failing CI on your default branch, failed deploys, bugs your customers report, vulnerable and outdated packages, committed secrets, and security audits.
- **Customer bug reports:** a bug reported in words, on a support ticket, a GitHub issue or in the dashboard, is reproduced with a failing test before it is fixed. The customer hears back once the fix is live. [How it works](https://bugstack.ai/customer-bug-reports)
- **How you stay in control:** each repository has an autonomy level (Suggest, Review or Autopilot). New repositories start on Review: Bugstack opens the pull request, you merge it.
- **Proof:** Bugstack's tester is first on the [SWT-Bench Verified leaderboard](https://swtbench.com/?results=verified). Predictions and traces are in [swt-bench-verified](https://github.com/Bugstackai/swt-bench-verified).
